1. Executive Summary & Architecture

This report details an end-to-end MLOps pipeline for predicting heart disease risk based on clinical patient attributes. Moving beyond offline model development, this architecture implements a production-grade lifecycle embracing automated data preprocessing, experiment lineage tracking, static code linting, automated testing, container isolation, cloud-native orchestration, and real-time observability.

2. Preprocessing & Model Evaluation

Data processing is fully automated inside a Scikit-Learn ColumnTransformer within src/preprocess.py, ensuring zero data leakage during cross-validation and online serving:

  • Numerical Features: Median value imputation followed by standard scaling (Z-score normalization).
  • Categorical Features: Most-frequent value imputation followed by One-Hot Encoding with handle_unknown='ignore'.

3. Continuous Integration & Quality Assurance

GitHub Actions manages the automated CI/CD pipeline (.github/workflows/ci_cd.yml). Upon code push to main, the pipeline executes:

  1. Static Code Linting: Flake8 verifies Python code style and checks for syntax errors.
  2. Automated Model Training: Runs python -m src.train to verify model reproducibility and log metrics to MLflow.
  3. Unit Testing Suite: Executes pytest tests/ -v verifying data ingestion, preprocessing output shapes, health check, and prediction endpoints.
  4. Container Image Verification: Builds the Docker image (heart-disease-api:latest) to validate container readiness.

4. Containerization & Kubernetes Orchestration

The FastAPI application is containerized using python:3.10-slim and orchestrated on Kubernetes with the following specifications:

  • High Availability: 2 pod replicas managed via k8s/deployment.yaml.
  • Health Probes: Liveness and Readiness HTTP probes querying /health every 10–15 seconds.
  • Resource Allocations: CPU Requests: 250m / Limit: 500m; Memory Requests: 256Mi / Limit: 512Mi.
  • External Exposure: Exposed via LoadBalancer service type (k8s/service.yaml) mapping external port 80 to container port 8000.
